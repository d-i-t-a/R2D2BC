Injectables Reader Demo
Injectable variants
1 Inline CSS
style-inline with a CSS string — no file hosted. Adds a red border to every chapter body.
2 Inline JS → postMessage
script-inline runs in the iframe and posts an event to the parent window. Pattern Clusive uses to notify the host app. See the log panel.
3 Blob CSS (dynamic theme)
style with blob — CSS built at runtime from a variable. No hosted file. Use for user-color-picker themes.
4 when — 3rd chapter only
Injects only when publication.readingOrder[2]'s href matches. MathJax-on-math-chapter pattern.
5 attributes passthrough
Sets data-* + crossorigin on the injected element. Also carries CSP nonce / SRI integrity. Inspect the iframe head in DevTools.
6 when — detect math in doc
when receives parsed doc. Outlines <math> elements in green only on chapters that contain MathML. Same pattern as conditional MathJax loading (only when needed).
7 when — chapter language
Reads doc.documentElement.lang. Adds a small banner on chapters tagged with a language (en, ja, etc.). Real use: inject per-language fonts or RTL rules.
